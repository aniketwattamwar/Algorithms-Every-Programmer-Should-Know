# Algorithms Every Programmer Should Know

Chapter files are grouped under [chapters/](chapters/) by book part.

For algorithm chapters, filenames distinguish the two file types:

- `ch_N_pseudocode_algorithm-name.md` contains the chapter notes and pseudocode.
- `ch_N_code_algorithm-name.py` contains the runnable Python implementation.

The language-of-algorithms and reflection chapters are conceptual and do not
have separate pseudocode or Python files.
